********************************************************Folder Description**************************************************************************

Calibration_points: Contains the 100 calibration points with measurement velocity and TUFLOW water depth values, provided for the Surrogate-assisted Bayesian calibration of the LYR 2D hydrodynamic model.

GPE_BAL_files: Contains the algorithm executed for the Bayesian calibration of the LYR 2D hydrodynamic model.

GPE_BAL_results: Contains the results of the calibration process (BME, RE, Posterior parameter lists, Telemac-2D results for posterior parameters at calibration locations).

LYR_measurement_values: Contains the velocity measurements and TUFLOW model results.

LaTeX_files: Contains the latex source files for compiling the master's thesis.

Model_preparation: All the files necessary for basic model preparations are present here. Simulation (steady, unsteady) files and results of Diego Beramendi's master's thesis are also provided. 

Unsteady_simulation_files: Test-1 and Test-2 unsteady simulation files are contained.

Unsteady_simulation_results: Contains the rasters of the calibrated model for Test-1 and Test-2. 

2022-11_Handique_Akash_MA.pdf: Final version of the master's thesis (submitted).
